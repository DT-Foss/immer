# IMMER Notice

IMMER integrates independently developed neural, causal, state, grounding,
attention, and exact-capability components behind one local runtime contract.

The repository distributes source code, manifests, tests, working-draft
papers, and small benchmark receipts. Large model weights, capability
artifacts, caches, live causal graphs, private route traces, credentials, and
operational records are excluded.

Canonical public components and revisions are recorded in
`manifests/components.json`.
