# Source inventory

The assembly inspected the newest available worktrees first and treated old
projects as historical references unless they supplied a unique runtime
contract. The resulting repository is intentionally a few kilobytes of
integration code rather than a copy of the source disks.

| Source | Current decision | Runtime material selected |
| --- | --- | --- |
| `self-verification_fable` | latest research authority | CRSA operators/audits, OrganBank/grafting entry points |
| `FERTIG` | active cognition source | unified solver order and exact solver boundary |
| `O1_juli` / `o1-state` | independent host | explicit adapter boundary only |
| `gssm-public` | independent research base | source reference only |
| `FORGE` | independent evidence runtime | provenance/replay reference only |
| `FLCA` | independent compiler/evidence repo | conservative route policy reference |
| `Liquid-QAD` | deployment experiment source | FERTIG bridge, FLCA bridge, CRSA/QAD boundary |
| `mirkoNN` | superseded | no code copied |
| `qwen-compress`, `KIMI`, `mitGLM` | historical | notes and contracts only |

Exact paths, commits, module mappings, and exclusions are machine-readable in
the two lock manifests. PDF drafts and mounted SDKARTE/LEXAR caches were used
as audit context only; they are not runtime dependencies and are not copied.
